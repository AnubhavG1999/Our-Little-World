# Spotify runs through a developer app on Anubhav's Premium account

"Now playing" and "listen together" talk to the Spotify Web API straight from the page (Authorization Code with PKCE, no server), through a Spotify developer app registered by Anubhav. Since Spotify's 2026 rules, a development-mode app only works while its owner has Premium and only for up to 5 allow-listed users, so: if Anubhav's Premium lapses, those features stop for both players; and both players' Spotify emails must stay on the app's user list. "Listen together" also needs both players on Premium with Spotify open, because Spotify offers no Jam/group-session API — it is a homemade "start this song on both devices", not true sync. The shared playlist player is a plain Spotify embed and works without any of this (phones may get 30-second previews only).
